# База данных

## СУБД

Microsoft SQL Server 2022 (Express в Docker)

## Коллация

**Важно:** база создаётся с `Cyrillic_General_CI_AS` для корректной работы с кириллицей.

```sql
CREATE DATABASE AviationDB COLLATE Cyrillic_General_CI_AS;
```

Если база создана с `SQL_Latin1_General_CP1_CI_AS`, кириллица будет отображаться вопросительными знаками.

## Основные таблицы

| Таблица | Описание |
|---------|----------|
| `PEOPLE` | Пользователи (пассажиры, админы, экипаж) |
| `SYSTEM_ROLES` | Роли: `admin`, `user`, `crew` |
| `PEOPLE_SYSTEM_ROLES` | Связь пользователь ↔ роль (M:N) |
| `FLIGHTS` | Рейсы |
| `FLIGHT_STATUSES` | Статусы: Планируется, Регистрация, Посадка, Вылетел, Прибыл, Отменён, Задержан |
| `AIRPORTS` | Аэропорты |
| `AIRLINES` | Авиакомпании |
| `AIRCRAFT` | Самолёты |
| `TICKETS` | Билеты |
| `TICKET_STATUSES` | Статусы билетов: Подтверждён, Отменён, Использован, Возвращён |
| `SEAT_CLASSES` | Классы мест: Эконом, Бизнес, Первый |

## Миграции

```bash
alembic revision --autogenerate -m "Описание"
alembic upgrade head
alembic downgrade -1
```

## Seed-данные

При старте контейнера автоматически создаются справочники (если их нет):

- **Системные роли:** `admin`, `user`, `crew`
- **Статусы рейсов:** Планируется, Регистрация, Посадка, Вылетел, Прибыл, Отменён, Задержан
- **Статусы билетов:** Подтверждён, Отменён, Использован, Возвращён
- **Классы мест:** Эконом, Бизнес, Первый

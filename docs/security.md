# Безопасность

## JWT-аутентификация

- **Алгоритм:** HS256
- **Срок жизни токена:** 24 часа
- **SECRET_KEY:** минимум 32 символа, валидатор в `app/core/config.py`
- **Хранение:** токен в `localStorage`, передаётся в заголовке `Authorization: Bearer`

## Ролевая модель

| Роль | Описание |
|------|----------|
| `admin` | Полный доступ ко всем операциям |
| `user` | Пассажир: просмотр рейсов, покупка билетов, профиль |
| `crew` | Член экипажа: управление назначениями |

Проверка роли в endpoint:
```python
@router.post("/flights/", dependencies=[Depends(require_admin)])
```

## 152-ФЗ — Персональные данные

**Собираемые ПДн:** ФИО, паспортные данные, телефон, email

**Меры защиты:**
- Пароли хешируются через bcrypt (не хранятся в открытом виде)
- При регистрации обязательный чекбокс согласия на обработку ПДн
- База данных с коллацией `Cyrillic_General_CI_AS`
- В production-логах не логируются чувствительные поля

## Rate Limiting (nginx)

| Зона | Лимит | Где применяется |
|------|-------|-----------------|
| `auth` | 5 запросов/мин | `/auth/login`, `/auth/register` |
| `api` | 100 запросов/с | Все остальные API endpoints |

## HTTPS

- SSL-сертификаты от Let's Encrypt
- Автообновление через certbot каждые 12 часов
- Принудительный редирект HTTP → HTTPS
